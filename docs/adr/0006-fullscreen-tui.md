# TUI 使用全屏消息区与底部输入区

Status: accepted

`neant` 采用 alternate screen 全屏展示：消息区可滚动，输入或审批区固定底部；退出恢复启动前的终端画面、光标和模式，Session 的持久化不受界面清理影响。仅交互式终端启动，本次不提供 `--inline` 选项，Headless CLI 保持当前行为。

这替代 ADR-0005 中 TUI 默认 inline 的选择。inline 把完成的消息交给终端 scrollback，退出后保留界面内容，无法满足独立滚动主体与固定输入区的要求。全屏模式需要由 TUI 管理消息浏览、底部跟随和阅读锚点，所有当前已展示条目仍保留；文本选择与复制沿用终端原生能力。自研渲染管线和 dsh-TUI 参考代码的复用边界仍沿用 ADR-0005。

用户浏览历史时暂停跟随，新输出只更新提示；回到底部或主动提交后恢复跟随，resize 保持阅读位置。输入区含分隔线最多 6 行且不超过终端高度三分之一，审批最多半屏并支持详情滚动；小于 40 列或 12 行时暂停编辑和审批，保留中断与退出。本次沿用现有 resume 的压缩后上下文投影。Q1–Q19 的完整确认记录、按键规则和验收范围见 [全屏 TUI 访谈](../../.scratch/fullscreen-tui/interview.md)；用户已确认最终共享理解并授权实施；验证结果见 [实施记录](../../.scratch/fullscreen-tui/implementation.md)。
