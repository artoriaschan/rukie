# 04：安装后的 TUI 与终端生命周期

Status: ready-for-agent
Blocked by: 03

## What to build

两种 macOS 架构的用户从安装后的 rukie 启动 TUI，看到完整头像资源，并在正常退出或中断后继续使用恢复正常的终端。

## Acceptance criteria

- [ ] 双架构安装包通过同一 rukie 入口选择 TUI，保留共用参数解析与 Headless 动态加载边界。
- [ ] 头像资源随产物携带并从安装位置或嵌入资源读取；从任意项目目录启动时可用，不以静默降级掩盖缺失资源。
- [ ] 从真实安装包以 PTY 启动，使用正常设置连接本地 fake provider，并验证代表性输入及模型响应。
- [ ] 正常退出和信号中断恢复终端模式及光标，等待 Session 保存和资源释放；launcher 不造成重复信号或遗留进程。
- [ ] 覆盖代表性 resize 与小终端场景，以及可见的恢复 Session 提示；其他既有交互覆盖保持通过。
- [ ] arm64/x64 都有匹配 runtime 的运行证据；源码 app helper 的测试不能替代安装产物 PTY 验收。
- [ ] 清理以终端谓词、完成信号或进程退出同步，有诊断性超时，不使用固定等待作为同步。
- [ ] 更新安装后的交互使用说明及验收证据，保持 Yoga 实现与既有范围例外。
