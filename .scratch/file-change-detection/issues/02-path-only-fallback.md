# 02: diff 超限、二进制、读取失败时只列路径

**What to build:** 改动太大、文件非文本、或读取出错时，reminder 不附 diff，只列路径并提示"修改前请重新 read"，且 Run 不中断。这些文件被标记为 stale，供后续过期检查使用。详见 [文件外部修改检测 spec](../spec.md) 的报告规则与失败行为两节。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 单文件 diff 超 4,000 字符只列路径
- [ ] 累计超 16,000 字符后余下文件只列路径
- [ ] 非 UTF-8 文本只列路径
- [ ] 非 ENOENT 的 stat / read 错误只列路径，不抛出
- [ ] 只列路径时基线 hash / mtime / size 更新为当前值（不重复报告）、丢弃内存内容、标记 `stale`
- [ ] e2e：大改动、多文件超总量、二进制文件三种情形各自只列路径，且不重复报告
