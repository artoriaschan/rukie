# 09: 主界面粗稿

Type: prototype

Blocked by: 07, 08

Status: resolved

## Question

按 Pencil 视觉稿布局，以 shadcn/ui 为基础组件、beUI 承担动效与执行反馈，MVP 主窗口（项目与 Session 侧栏、对话流、工具调用块、权限确认、输入区、断开与重连状态）应该长什么样、如何交互？产出可在浏览器打开的粗糙 React 原型供评审。参照画板见 [08](08-task-pencil-design-source.md#answer)；视觉稿未覆盖的工具调用块与权限审批卡片在原型中先给出方案。样式严格遵循 [DESIGN.md](../../../DESIGN.md)，registry 默认值与之冲突处按 DESIGN.md 改写，并在答案中列出改写点。

## Answer

用户于 2026-10-10 确认第九轮粗稿。原始资料在 `origin/prototype/desktop-main-window`（HEAD `ba40fd5d`），`prototypes/desktop-main-window/` 下执行 `npm install && npm run dev`，然后打开 `http://localhost:5199/`。分支不合并，各轮细节见下方 Comments。

- 窗口：窗口底色承载通栏标题栏与左侧导航栏。标题栏有交通灯、侧栏开关、类型图标（tooltip 显示项目名）、Session 标题、更多与摘要开关。导航栏 MVP 只有首页（实心图标 + 浅色底块）和底部头像。侧栏与主区域合成一张左上圆角的内容面板。
- 侧栏：顶部为“新聊天”（⌘N）与搜索（⌘K 打开命令浮层），下面是置顶、对话、项目、最近四个可折叠分组。分组标题的图标只在 hover 时出现。会话行不显示时间，只显示运行或待确认状态，按住 Ctrl 显示 ⌃1–⌃9。项目行只用文件夹图标表示展开状态，hover 时出现更多菜单与新建会话。
- 主区域：新会话显示欢迎页加输入框，可切换项目或默认工作区；历史会话显示对话加输入框。已完成的 Turn 折叠在“用时 …”后，当前 Turn 完整展开；工具调用为单行，失败时展开输出。左缘 Turn 刻度在 hover 时显示预览。权限审批停靠在输入框上方，按 Agent Core 的 `allow` / `allow-session` / `deny` 回复，回复后在 Turn 内留一行结果。断连时禁用回复。会话摘要卡片固定在右上角。
- 输入框：附件、权限模式菜单（每个模式带说明）、上下文用量环与用量面板、模型列表（hover 显示详情与推理档次，档次取自 Agent Core `THINKING_LEVELS`）、发送或停止。
- 菜单：会话更多菜单、项目菜单与账户菜单（只有使用情况与设置）。所有纯图标按钮都有 tooltip。
- DESIGN.md 改写点：颜色全部改为 GitHub Light/Dark token；字号全部改为 `text-ui-*`；文案全部改为 zh/en 字典。Pencil 稿中的 Codex/ChatGPT 文案、模型倍率与估计费用不纳入 MVP。
- 组件来源：用户同时将规则改为 beUI 优先、shadcn 补位，DESIGN.md、AGENTS.md 与 tech-stack 已同步。粗稿为 shadcn 风格的手写实现，只提供布局与交互；正式实现按新规则选取组件。
