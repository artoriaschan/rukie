# 05：「+」插入列表与 `/goal`、`/plan` 内置命令

Status: ready-for-agent
Blocked by: 03

**What to build:** 按 [spec](../spec.md) 的「插入列表」一节，让「+」与 `/` 共用同一个插入列表，并加入内置命令组。用户点击「+」能看到附件、内置命令和全部技能；目标模式与计划模式改由 `/goal`、`/plan` 承担。

- [ ] `/` 列表新增「内置命令」组，排在「技能」之前；首批 `/goal`、`/plan`，描述、开关或开/关状态、可用性与原「+」菜单一致，不可用时为不可用选项并显示原因
- [ ] 「+」打开同一插入列表，三组「添加（附件）/ 内置命令 / 技能」，全部列出，无搜索；替换原下拉菜单
- [ ] 从「+」选中技能时插到开头并保留正文；选中 `/goal`、`/plan` 执行动作且不改输入
- [ ] 「+」列表打开时，在开头输入 `/` 切换为 `/` 列表，其他输入关闭「+」列表并照常输入
- [ ] Run 进行中列表照常可用，`/goal`、`/plan` 的可用性跟随原规则
- [ ] 内置命令行同样遵守单行布局与右侧内容固定的规则
- [ ] 按布局保护流程更新「+」区域基线，输入框几何不变；浏览器测试覆盖两种入口的分组、切换、执行与无障碍语义
- [ ] zh 与 en 文案同步更新
