# 08：输入框中的 `/mcp` 状态

Status: ready-for-agent
Blocked by: 05, 07

**What to build:** 按 [spec](../spec.md) 的「插入列表」「状态接口」两节，在内置命令中加入 `/mcp`：一级行显示 MCP 汇总，进入后列出每个 MCP Server 的来源、状态与工具数。新会话页在没有 Session 时也能看到实时状态。

- [ ] wire 新增 MCP 状态查询命令（项目或会话标识）与状态变化事件，按项目视图返回；无项目时返回全局单例，并把引用项目目录的用户级 server 标为需要项目；只读查询不启动进程，进入 `/mcp` 或选中项目时租用视图并在离开后释放
- [ ] `/mcp` 一级行描述「查看 MCP 服务状态」，右侧汇总「x个MCP已连接 · x个工具可用 · x个MCP连接中 · x个MCP需要授权 · x个MCP连接失败」，数量为 0 的分段隐藏；无 server 显示「未配置 MCP」，首次加载显示「加载中」；过长截断并悬停全文；实时更新
- [ ] 回车、Tab 或点击进入二级列表，输入保留 `/mcp ` 并按服务名过滤；Esc 或删掉 `/mcp` 回上一级，再按 Esc 关闭并清空
- [ ] 二级行左侧 MCP 图标与名称，右侧「来源 · 状态」，已连接时追加「 · N个工具」；连接失败悬停显示原因；配置错误单独一行；无 server 显示「未配置 MCP 服务」；引用项目目录且未选项目显示「全局 · 选择项目后启动」
- [ ] 二级行为不可用选项，回车不发送 `/mcp`，不插入会话；读屏读出名称、来源、状态与工具数
- [ ] 新会话页切换项目时刷新；会话内读取该 Session 的项目视图
- [ ] server 测试覆盖命令校验、无项目与事件推送；浏览器测试覆盖汇总、各状态、过滤、进入退出与无障碍语义；zh 与 en 文案同步
