# Spec: 主输入框插入技能与 MCP Host

来源：本分支的设计访谈（含对 Claude Code、ZCode、deepseek-harness 与程小帮 v1.9.2 的调研）。术语见 `CONTEXT.md` 中的 Skill、Skill Invocation、Slash Command、MCP Server、MCP Host、MCP Credential、Trusted Project、Session、Run、Turn。架构决定见 [ADR-0047](../../docs/adr/0047-host-owned-mcp-connections.md) 与 [ADR-0048](../../docs/adr/0048-lexical-composer-editor.md)。

## Problem Statement

桌面和 Web 的主输入框是普通 textarea，没有 `/` 菜单。用户看不到可用技能，只能记住名称手打 `/name`，也无法确认它会被识别为 Skill Invocation。

输入框里看不到 MCP Server 的状态。MCP 连接和状态现在属于每个 Session：新会话页还没有 Session，拿不到状态；同一项目的多个 Session 各自启动同一批 server；TUI 切换 Session 会重新连接。连接意外断开后不会自动恢复，server 变更工具列表后也要显式重连才能看到。

## Solution

- 主输入框改用 Lexical 纯文本编辑器。输入框上方显示插入列表，入口有两个：点击「+」，或在输入开头输入 `/`。
- 选中技能后，输入框开头出现技能标记（图标加技能名称，蓝色）。发送时仍是 `/名称 正文`，Agent Core、TUI 与 Transcript 的 Skill Invocation 语义不变。
- 内置命令 `/mcp` 显示 MCP 汇总，进入后列出每个 MCP Server 的来源、状态和工具数，只读，不插入会话。
- MCP 连接上移到进程级 MCP Host：用户级 server 默认是全局单例，项目 server 按项目一份；Session 只租用连接。新会话页和会话内读取同一份实时状态。连接有断线监督，并同步 server 的工具列表变更。

## User Stories

1. 作为桌面用户，我想点击「+」看到附件、内置命令和全部技能，以便不记名称也能找到要用的能力。
2. 作为桌面用户，我想在输入框开头输入 `/` 时只看到内置命令和技能，以便用键盘快速选择。
3. 作为用户，我希望插入列表始终显示在输入框上方、与输入框同宽，不遮住正在输入的内容。
4. 作为用户，我希望内置命令排在技能前面，每组有组标题，过滤后为空的组连同标题一起隐藏。
5. 作为用户，我希望 `/` 后输入的文字按名称过滤列表，不区分大小写，前缀匹配排在前面。
6. 作为用户，我希望过滤后没有任何匹配时列表关闭，回车把 `/xxx` 当普通文本发出。
7. 作为用户，我希望「+」列表打开时在开头输入 `/` 会切换成 `/` 列表，输入其他字符则关闭「+」列表并照常输入。
8. 作为键盘用户，我希望焦点留在输入框，用上下键移动高亮，回车或 Tab 选中，Esc 关闭。
9. 作为用户，我希望列表最多显示 10 个可选项，超出时在列表内滚动，高亮项始终可见。
10. 作为用户，我希望每个技能行显示图标、名称、跟在名称后的描述，以及右侧「全局」或「项目」来源标签。
11. 作为用户，我希望描述放不下时截断并显示省略号，悬停看全文，右侧标签始终完整。
12. 作为窄窗口用户，我希望行宽不足时先收起描述、再截断名称，右侧内容最后才截断。
13. 作为用户，我希望全局和项目有同名技能时只看到实际生效的项目版本。
14. 作为用户，我希望技能按名称字母顺序排列。
15. 作为用户，我希望选中技能后输入框开头出现「图标 + 技能名称」的蓝色技能标记，光标停在标记后并自动补一个空格。
16. 作为用户，我希望技能标记作为整体删除，光标进不到标记内部。
17. 作为用户，我希望一条消息最多一个技能标记，再选一个技能会替换原来的。
18. 作为用户，我希望从「+」选中技能时，已输入的正文保留在标记后面。
19. 作为用户，我希望只有技能标记、没有正文时也能发送。
20. 作为用户，我希望发出的消息在历史中同样显示技能标记，即使技能后来被删除。
21. 作为用户，我希望复制含技能标记的内容得到 `[$名称](/绝对路径/SKILL.md)` 形式的 Markdown 链接。
22. 作为用户，我希望把这种链接粘贴到输入框开头时还原成技能标记，粘贴到其他位置时作为普通文本。
23. 作为用户，我希望从历史消息复制时，技能标记部分同样变成 Markdown 链接；找不到技能文件时退回 `/名称`。
24. 作为用户，我希望 `/mcp` 一行右侧显示「x个MCP已连接 · x个工具可用 · x个MCP连接失败」这类汇总，数量为 0 的分段不出现。
25. 作为用户，我希望汇总也区分「连接中」和「需要授权」，并随状态变化实时更新。
26. 作为用户，我希望没有任何 MCP Server 时汇总显示「未配置 MCP」，首次加载时显示「加载中」。
27. 作为用户，我希望在 `/mcp` 上按回车、Tab 或点击进入 MCP 列表，并用 `/mcp ` 后的文字按服务名过滤。
28. 作为用户，我希望每个 MCP 行左侧是图标和名称，右侧是「来源 · 状态」，已连接时追加工具数，例如「项目 · 已连接 · 12个工具」。
29. 作为用户，我希望连接失败的行悬停可以看到原因，配置文件错误单独占一行。
30. 作为用户，我希望 MCP 列表只供查看，回车不会发送 `/mcp`，也不会插入会话。
31. 作为用户，我希望按 Esc 或删掉 `/mcp` 回到上一级，再按 Esc 关闭并清空输入框。
32. 作为没有选择项目的新会话用户，我希望看到全局技能和全局 MCP Server 的实时状态；引用项目目录的 server 显示「选择项目后启动」。
33. 作为新会话用户，我希望切换项目后技能列表和 MCP 状态随之更新。
34. 作为用户，我希望 `/goal`、`/plan` 出现在内置命令中，行为、可用性和右侧状态与原「+」菜单的目标模式、计划模式一致。
35. 作为 Run 进行中的用户，我希望插入列表照常可用，选中技能后发送的消息作为插话提交。
36. 作为读屏用户，我希望输入框以组合框声明列表展开状态和当前高亮项，MCP 行以不可用选项读出名称、来源、状态和工具数。
37. 作为同一项目开多个会话的用户，我希望它们共用 MCP 连接，不重复启动 server 进程。
38. 作为 TUI 用户，我希望 `/resume`、`/clear` 换 Session 时 MCP 不重新连接。
39. 作为用户，我希望 MCP Server 意外断开后自动退避重连，多次失败后显示失败而不是无限重启。
40. 作为用户，我希望 server 更新工具列表后，下一个 Turn 就能用上新工具，不需要手动重连。
41. 作为用户，我希望修改 MCP 配置后，下次发消息或打开 `/mcp` 时按新配置连接。
42. 作为用户，我希望中止一个 Run 不会断开其他会话正在使用的 MCP 连接。
43. 作为用户，我希望同一 HTTP MCP Server 只需登录一次，所有会话和项目都能使用。
44. 作为配置 MCP 的用户，我希望用户级 stdio server 默认只运行一份；需要按项目运行时在配置中引用 `${RUKIE_PROJECT_DIR}`。
45. 作为 Headless 用户，我希望 MCP 行为与现在一致，不出现授权交互。

## Implementation Decisions

### 编辑器

- 主输入框改用 Lexical 纯文本编辑器，依赖按精确版本锁定并记入 tech-stack。保持现有行为：回车发送、Shift+回车换行、输入法合成不触发发送、图片粘贴、焦点交接、受保护的输入框几何。见 [ADR-0048](../../docs/adr/0048-lexical-composer-editor.md)。
- 输入框对外仍以纯文本草稿和图片作为发送输入；技能标记只存在于编辑器状态，由序列化函数转成 `/名称 正文`。

### 插入列表

- 一个插入列表组件服务两个入口，显示在输入框上方、与输入框同宽，复用已安装的弹出层组件。
- 「+」入口三组：添加（附件）、内置命令、技能。全部列出，无搜索。原「+」下拉菜单的目标模式、计划模式改由 `/goal`、`/plan` 两行承担，开关、开/关状态与说明随之迁移。
- `/` 入口：仅当整个输入以 `/` 开头、光标在首行且 `/` 后无空白时出现，两组：内置命令、技能。按名称过滤，不区分大小写，前缀匹配优先，不匹配描述。无匹配时关闭，Slash Command 未匹配的输入原样交给 Agent Core。
- 「+」列表打开时，在开头输入 `/` 切换为 `/` 列表；其他输入关闭「+」列表。
- 焦点始终在输入框。列表接管上下键、回车、Tab、Esc；鼠标点击选中。
- 首版内置命令：`/mcp`、`/goal`、`/plan`。`/goal`、`/plan` 的可用性与原菜单规则一致。不保留无数据来源的「命令」分组。
- 行布局单行：图标加名称、描述、右侧内容。右侧内容固定不压缩；名称在超过上限时才截断；描述占剩余宽度并截断，悬停显示全文。宽度不足时依次收起描述、截断名称，最后才截断右侧内容。
- 最多显示 10 个可选项，组标题不计入，超出时列表内滚动并保持高亮可见。
- 无障碍：输入框为组合框并声明展开与当前高亮项；列表分组带标题；MCP 行和不可用的 `/goal` 为不可用选项。
- 每次打开列表先显示缓存，再后台刷新技能列表与 MCP 状态；新会话页按选中项目取数，切换项目时刷新。
- 所有颜色、间距、行高、圆角、图标尺寸使用 DESIGN.md 已有角色；缺少的技能标记与插入列表规范先补进 DESIGN.md。「+」从下拉菜单改为插入列表属于用户授权的布局变化，按布局保护流程更新该区域基线。

### 技能标记

- Lexical TextNode 的 token 模式自定义节点，节点文字是技能名，整体删除、光标不可进入。图标由样式表绘制，不进入节点文字；颜色使用 DESIGN.md 的 accent/link 角色。
- 每条消息最多一个，只能是第一个节点；再选技能时替换。从 `/` 选中时替换 `/xxx`，从「+」选中时插到开头并保留正文。插入后光标在标记后，并补一个空格。
- 序列化：发送 `/名称 正文`；只有标记时发送 `/名称`。Agent Core 的 Skill Invocation 匹配规则不变。
- 剪贴板：`text/plain` 与 `text/html` 都输出 `[$名称](/绝对路径/SKILL.md)` 字面文本，HTML 不做可点击链接；Lexical 内部格式保存节点数据。节点的 `getTextContent()` 仍返回名称，复制格式由剪贴板导出处理。
- 粘贴：自定义处理器优先于纯文本默认处理。Lexical 内部格式中的技能节点、或以 `[$名称](…SKILL.md)` 开头且名称是当前可用技能的文本，粘贴位置在开头时还原为标记，否则降级为文本。
- 历史消息：依据持久化的 `skillInvocation` 事实把开头的 `/名称` 渲染为同一标记，不用当前技能列表重新判断；从历史复制时用当前技能列表补全路径，找不到时输出 `/名称`。

### 技能数据

- Agent Core 的技能列表结果增加 `scope`（`user` 或 `project`）与 `filePath`。scope 由发现根决定：用户级技能目录为 `user`，项目目录为 `project`；同名时项目覆盖用户，列表只返回生效项。
- wire 新增不依赖 Session 的技能列表命令，参数为项目或会话标识；无项目时只返回用户级技能。

### MCP Host

- 每个进程一个 MCP Host，在一张全局连接表中维护全部 MCP Server 连接，见 [ADR-0047](../../docs/adr/0047-host-owned-mcp-connections.md)。Session 不再创建自己的连接；未注入 MCP Host 时，Session 创建私有 MCP Host 并随 Session 关闭。server、TUI、Headless 各自在进程级创建一个并注入。
- 连接作用域与启动目录：

| 来源                                           | 作用域       | stdio 启动目录                         |
| ---------------------------------------------- | ------------ | -------------------------------------- |
| 用户级 server，配置未引用项目目录              | 全局单例     | 配置的 `cwd`，否则 `homeDir`           |
| 用户级 server，配置引用 `${RUKIE_PROJECT_DIR}` | 每个项目一份 | 配置的 `cwd`（相对项目根），否则项目根 |
| 项目 `.mcp.json` 中的 server                   | 每个项目一份 | 配置的 `cwd`（相对项目根），否则项目根 |

- 连接键由作用域、server 名和展开后配置的稳定签名组成。签名变化即新建连接，旧连接在进行中的调用结束后关闭。
- 项目视图：给定项目（或无项目）解析生效的 server 集合，项目级 server 覆盖同名用户级 server；视图引用全局表中的连接。不做跨名称的同端点仲裁。
- 租约：Session 通过项目视图租用连接，子代理共用父 Session 的租约。项目实例在最后一个租约释放 30 秒后关闭；全局单例保留到进程退出，配置变化时按签名替换。
- 启动：全局单例在 MCP Host 创建时后台并行连接（stdio 并发 3、远程并发 8）。项目实例在首次被租用时连接；TUI 与 Headless 启动时租用 cwd 对应项目。连接过程不发起 OAuth。
- 重读配置：发送用户消息前、原生 Run 开始前、打开 `/mcp` 时；并发重读合并；不监听配置文件。
- Run 开始前等待仍在连接中的 server 落定；中止 Run 只取消等待，不关闭共享连接。
- 断线监督：意外关闭后状态为连接中，指数退避重连（初始 1 秒、上限 30 秒、最多 5 次），连续健康连接满 30 秒后计数清零，初始化成功或短暂恢复不清零；重连前确认旧一代连接已关闭；需要授权的 server 不进入重连；断线期间工具调用直接向模型返回错误。
- 工具同步：订阅 `tools/list_changed`，每个 server 串行同步，新一代整体替换，失败保留上一代并告警。工具注册绑定连接而非某一代 client，名称保持 `mcp__<server>__<tool>`；根 Session 与子代理在 Turn 边界读取工具集，包括同名工具的描述与 Schema 变化，沿用现有 loadout 漂移检测。
- 授权：needs-auth、被拒 token、授权范围与进行中的授权流程挂在连接上，并发授权去重；Interaction 由发起方 Session 的回调提供，发起方取消时共享等待者收到取消结果。登录、登出、重连在该 server 有进行中的调用时返回 busy。MCP Credential 的身份与存储不变。
- Session 继续提供 `mcpServers()` 及管理方法，返回其项目视图快照；`mcp_servers_changed` 由视图变化驱动。MCP reminder、Hook 调用 MCP、`authenticate` 工具的暴露规则不变。

### 状态接口

- `McpServerView.status` 新增 `pending`，表示连接中或重连中；非已连接状态工具数为 0。
- MCP Host 按项目视图返回快照并推送变化。wire 新增 MCP 状态查询命令（参数为项目或会话标识）与状态变化事件；新会话页与会话内使用同一来源。无项目时返回全局单例，并把引用项目目录的用户级 server 标为需要项目。
- 只读查询不启动进程；显示已有 Session、选中项目或进入 `/mcp` 时租用活动视图并触发连接，切换范围或断开时释放原视图。未选项目的新会话普通摘要只观察；退出详情后按当前 Session／项目范围恢复订阅。

### MCP 配置格式

- 用户级 stdio server 新增可选 `cwd`。`args`、`env`、`cwd` 支持保留变量 `${RUKIE_PROJECT_DIR}`，只在用户级配置中有意义。
- 行为变化：用户级 stdio server 不再隐式使用 Session cwd，依赖当前目录的配置需改为引用 `${RUKIE_PROJECT_DIR}`。

### 文档

- 更新 docs/mcp.md 的配置、连接归属与 Frontend 接口章节；修正 docs/architecture.md 中「MCP 连接属于一次 Run」的描述；DESIGN.md 补技能标记与插入列表规范；tech-stack 记录 Lexical。

## Testing Decisions

好的测试只验证公开行为：Session、MCP Host 与 wire 的可观察结果，输入框在真实浏览器中的 DOM、焦点与发送内容，不断言内部数据结构。测试缝从高到低选择，尽量复用现有缝：

- **Agent Core：`createSession` 加注入的 MCP Host。** 沿用 `packages/agent/tests/e2e/mcp*.test.ts` 的 fake MCP server 与 fake model 辅助。覆盖：多个 Session 共享同一连接；全局单例与项目实例的作用域和启动目录；`${RUKIE_PROJECT_DIR}` 切换作用域；配置签名变化换新连接；租约释放后 30 秒关闭（虚拟时钟，断言截止前与截止时）；意外断开的退避重连与上限；`tools/list_changed` 整代替换与失败保留；中止 Run 不关闭共享连接；授权并发去重与发起方取消；快照 `pending` 状态与变化事件。改写约 108 个现有 MCP 生命周期测试与 15 个 TUI MCP 面板测试以适配新归属，不削弱断言。
- **技能列表：** 在现有技能测试中验证 `scope`、`filePath` 与同名覆盖。
- **server：wire 命令测试。** 沿用 `packages/server/tests/server.test.ts`，覆盖技能列表与 MCP 状态命令的参数校验、无项目行为与状态事件推送。
- **ui：Chromium 浏览器模式组件测试。** 沿用 `packages/ui/tests/components/composer.browser.test.tsx`、`compact-composer.browser.test.tsx`、`input-focus.browser.test.tsx` 与注入的 client。覆盖：两个入口的分组、过滤、切换与关闭；键盘与组合框语义；10 项高度与滚动；窄宽度收缩；技能标记的插入、替换、整体删除、序列化；复制粘贴三种格式；历史标记渲染；`/mcp` 汇总与列表状态；回车、输入法、图片粘贴回归；「+」区域布局基线。
- 最终按根规则在 Chromium 中做 Light/Dark/窄宽度验收；MCP Host 属于共享生命周期改动，交付前本地运行一次完整检查。

## Out of Scope

- 桌面端添加用户级 MCP Server、全局技能的设置入口，以及桌面 MCP OAuth 登录入口。
- 在会话中插入或引用 MCP Server、tool、prompt、resource；MCP prompts 与 resources 支持。
- 多个技能标记或在正文中间插入技能；自定义命令。
- 有状态 stdio server 的按会话隔离开关；跨名称同端点仲裁；MCP `roots`；配置文件监听。
- TUI 的 `/` 菜单与面板交互变化（仅适配 MCP Host 归属）。

## Further Notes

- 交付通过一个分支、一个合并请求完成。
- 桌面端当前只有受信任项目的 `.mcp.json` 可写入 MCP 配置，短期内全局 MCP 列表通常为空。
- 共享连接使有状态 stdio server（如浏览器自动化）被多个 Session 同时使用，这与 Claude Code、Claude Desktop 一致。
