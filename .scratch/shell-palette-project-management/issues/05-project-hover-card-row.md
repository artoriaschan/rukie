# 05：项目详情卡与项目行

Status: ready-for-agent

Blocked by: 04

**What to build:** 按 [spec](../spec.md#项目详情卡c30与项目行)，实现侧栏项目行的悬停与选中状态，以及悬停或聚焦时显示的项目详情卡 C30。

- [ ] 开始改动前记录 sidebar 与 layout 的 layout preservation 基线
- [ ] 项目行：32px、8px 圆角，`hover` 与 `selected` 背景（当前会话属于该项目时为 `selected`）；hover 或 focus-within 时只显示“新建会话”（空间预留）；不渲染“⋯”与右键菜单；侧栏宽度和会话行几何不变
- [ ] C30：320px；名称与图钉、会话数（未归档，含置顶）、目录完整路径（`~` 缩写）、“编辑项目”行；由已安装的 beUI Popover 受控组合
- [ ] 打开：停留约 300ms 或获得键盘焦点；关闭：离开约 150ms 后或按 Esc；以门户渲染，距悬停背景右边缘 4px、顶边对齐，可覆盖中间导航并按视口夹取；指针可穿过间隙进入卡片
- [ ] 图钉临时固定，固定后再次点击图钉、按 Esc 或点击外部关闭，状态不持久化；“编辑项目”关闭卡片并打开 C29
- [ ] 打开状态可由外部关闭，为将来“⋯”菜单与详情卡互斥预留
- [ ] zh 与 en 文案同步
- [ ] 浏览器测试：使用虚拟时钟验证延迟截止前与截止时的状态、键盘打开、穿越间隙、图钉、Esc 与外部点击、编辑入口、会话数、锚定矩形；项目行 hover 与选中背景
