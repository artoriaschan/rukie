- [ ] 计划及其他 Markdown 内容复用 01 的呈现，展开入口、滚动、正文选择与卡片动作边界清楚。

- [ ] 问题、审批及其他现有面板共存时按键、滚轮与焦点归属正确，缺失回调和 Run 中断行为不改变。
- [ ] 通过现有 start/startWithClock 和必要的 createSession 入口覆盖特殊路由、各种交互结果、恢复和中英文，不验证私有投影代替外部行为。
- [ ] 小终端、resize 和阅读位置保持既有规则，必要新增持久化事实在本工单实现，不将恢复能力全部推迟到 11。
