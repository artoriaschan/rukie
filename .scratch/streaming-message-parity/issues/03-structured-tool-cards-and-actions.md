# 03: 结构化工具卡与操作入口

Status: ready-for-agent
Blocked by: 01

**What to build:** 用户在实际工具调用中看到结构化标题、运行与结果状态、参考预览和交互入口，能展开输出或操作文件路径，各个动作互不误触。

规范用户故事：13–17、21–25、41、55、60–61。

以 dsh-TUI `3c89ea516e4f7d2777efe979200016528722a0b4` 和父规范为准。保留 Neant 品牌、中英 Locale、Session 权限与生命周期；缺失信息不伪造，不新增老会话兼容。必要数据、消费者、公开行为测试和所属文档在本工单一起交付，使用现有 start/startWithClock 与必要的 createSession 入口。开发运行最小受影响检查，代码交付遵循仓库完整验证规则。

## Acceptance criteria

- [ ] read、terminal、diff、search 和 generic 等 Tool View 按参考呈现，涵盖内置和适用的 MCP 工具；标题、分类色、标记与内容槽一致。
- [ ] 运行、成功、失败和结果未知可区分；同名并发调用以调用身份正确关联，开始与结果只形成一张对应卡片。
- [ ] 普通输出默认三行、diff 默认八行预览，支持单卡展开与收起；hover、箭头、标题截断和可点击区域对齐参考，空白区域不误触。
- [ ] 新的运行中工具调用正文参与平滑显示；结果、错误与展开内容直接完整显示，非零退出码和信号在折叠状态仍可见。
- [ ] 文件或文件夹的打开、文件管理器定位和绝对路径复制通过现有 host 边界工作，路径、图片入口和卡片折叠互不误触。
- [ ] 缺失视图或真实字段使用规范定义的通用／未知呈现；不伪造成功、耗时或完整源，不额外持久化 Tool View。
- [ ] 新会话恢复从 Transcript 重算对应呈现，调用及结果顺序一致；未知结果不自动重放，必要新增事实由本工单保存并验证。
- [ ] 通过 start/startWithClock 驱动实际工具调用并检查终端单元格和 host 可观察结果；覆盖并发同名工具、错误、未知结果、中英文与 resize。
