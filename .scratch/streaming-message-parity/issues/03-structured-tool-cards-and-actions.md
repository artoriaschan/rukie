## Acceptance criteria

- [x] read、terminal、diff、search 和 generic 等 Tool View 按参考呈现，涵盖内置和适用的 MCP 工具；标题、分类色、标记与内容槽一致。
- [x] 运行、成功、失败和结果未知可区分；同名并发调用以调用身份正确关联，开始与结果只形成一张对应卡片。
- [x] 普通输出默认三行、diff 默认八行预览，支持单卡展开与收起；hover、箭头、标题截断和可点击区域对齐参考，空白区域不误触。
- [x] 新的运行中工具调用正文参与平滑显示；结果、错误与展开内容直接完整显示，非零退出码和信号在折叠状态仍可见。
- [x] 文件或文件夹的打开、文件管理器定位和绝对路径复制通过现有 host 边界工作，路径、图片入口和卡片折叠互不误触。
- [x] 缺失视图或真实字段使用规范定义的通用／未知呈现；不伪造成功、耗时或完整源，不额外持久化 Tool View。
- [x] 新会话恢复从 Transcript 重算对应呈现，调用及结果顺序一致；未知结果不自动重放，必要新增事实由本工单保存并验证。
- [x] 通过 start/startWithClock 驱动实际工具调用并检查终端单元格和 host 可观察结果；覆盖并发同名工具、错误、未知结果、中英文与 resize。
