# Spec: 首页会话侧栏重构、会话菜单与搜索浮层

## Problem Statement

桌面端首页会话侧栏有置顶、对话、项目、最近四个分区，同一个 Session 会在多个分区里重复出现，列表很长，难以浏览。会话行只有一个 hover 置顶按钮，用户不能重命名、归档或删除 Session，旧 Session 只能一直留在列表里。侧栏使用原生滚动条，布局与 rukie.pen C02 不一致。新聊天右侧的搜索打开的是通用 CommandPalette，只列出最近 8 条 Session，样式与 C25 不一致，也没有快捷操作。

## Solution

- 侧栏按 rukie.pen C02 重构：分类改为“置顶 → 项目 → 对话”三种，删除“最近”。每个 Session 只出现一次。有置顶 Session 时才渲染“置顶”分类。
- 会话行 hover 时显示置顶 icon 和更多 icon。点击更多 icon 与右键 Session 展示同一份菜单，样式参考 C22，只包含重命名、置顶/取消置顶、归档、永久删除，右侧不展示快捷键。标题栏“会话更多”菜单也提供这四项操作。
- 重命名打开“重命名聊天”弹窗。重命名未打开的 Session 时不打开 Session、不触发 Session Resume。
- 归档把 Session 变为 Archived Session，从侧栏和搜索中隐藏。永久删除经确认后移除 Session 的全部存储。
- 搜索 icon 打开 C25 搜索聊天浮层：自动聚焦的输入框、“聊天”结果分组和“快捷操作”分组。浮层打开与关闭带缩放和淡入淡出。
- 侧栏滚动按“C02 · 滚动容器高度受限 / 起始”和“/ 滚动后”实现：顶部新聊天行固定，分类与 Session 在其下滚动，使用 A13 自定义滚动条。

## User Stories

1. 作为桌面端用户，我希望侧栏只有置顶、项目、对话三个分类，这样列表更短，也更容易定位 Session。
2. 作为用户，我希望每个 Session 在侧栏里只出现一次，这样不会被重复条目干扰。
3. 作为用户，我希望不属于任何 Project 的 Session 列在“对话”分类里，这样默认工作区的 Session 有固定位置。
4. 作为用户，我希望 Project 下列出工作目录等于该 Project 路径的 Session，这样按项目查找 Session。
5. 作为用户，我希望没有置顶 Session 时不显示“置顶”分类，这样侧栏没有空分类。
6. 作为用户，我希望置顶的 Session 只出现在“置顶”里，取消置顶后回到所属 Project 或“对话”，这样置顶真正起到提到最前的作用。
7. 作为用户，我希望分类标题收起时在名称右侧常显向右箭头，展开时 hover 才显示向下箭头，这样能看出分类状态，又不增加视觉负担。
8. 作为用户，我希望 hover 分类标题时看到该分类的操作：置顶为更多，项目为更多和添加项目，对话为更多和新建会话，这样不用离开侧栏就能完成常用操作。
9. 作为用户，我希望分类内有执行中的 Session 时，分类标题右侧持续显示加载 icon，并且与 hover 操作同时可见，这样分类收起时也能知道有工作在进行。
10. 作为用户，我希望分类“更多”打开现有的侧栏选项菜单（整理、排序、显示），“显示”的勾选项对应置顶、项目、对话，这样可以控制显示哪些分类。
11. 作为用户，我希望一个 Project 的 Session 超过 5 条时只显示前 5 条，并出现“展开显示”行，这样长项目不会占满侧栏。
12. 作为用户，我希望 Project 超过 5 个时只显示前 5 个，并出现“展开显示”行，这样项目分类保持紧凑。
13. 作为用户，我希望过长的 Session 标题在末尾渐隐而不是被硬截断，这样与 C02 一致。
14. 作为用户，我希望 hover 或键盘聚焦会话行时在右侧看到置顶 icon 和更多 icon，这样可以快速置顶或打开菜单。
15. 作为用户，我希望已置顶 Session 的置顶 icon 显示为取消置顶，这样同一个按钮可以撤销置顶。
16. 作为用户，我希望会话行继续显示执行中和等待确认指示，以及按住 Ctrl 时的序号提示，这样现有反馈不丢失。
17. 作为用户，我希望右键 Session 时在指针附近出现会话菜单，这样可以用习惯的方式操作。
18. 作为用户，我希望点击更多 icon 出现的菜单与右键菜单内容一致，这样两个入口不会让我困惑。
19. 作为用户，我希望菜单只有重命名、置顶、归档、永久删除四项，且右侧不显示快捷键，这样菜单只展示已经可用的能力。
20. 作为用户，我希望“永久删除”用危险色显示，这样不会误认为普通操作。
21. 作为用户，我希望标题栏“会话更多”菜单也能重命名、归档和永久删除当前 Session，这样在会话内也能完成这些操作。
22. 作为用户，我希望点击“重命名”后出现“重命名聊天”弹窗，副标题为“保持简短且易于识别”，这样清楚要做什么。
23. 作为用户，我希望弹窗打开时输入框已填入当前标题、全选并聚焦，这样可以直接输入新名称。
24. 作为用户，我希望输入为空、只有空白或与原标题相同时“保存”不可用，这样不会提交无效修改。
25. 作为用户，我希望按 Enter 保存，按 Esc、点 × 或“取消”关闭弹窗且不修改，这样键盘可以完成整个流程。
26. 作为用户，我希望保存失败时弹窗保持打开并显示错误，这样我知道改名没有成功。
27. 作为用户，我希望改名后标题固定，不再被模型自动生成的标题覆盖，这样我起的名字会保留。
28. 作为用户，我希望重命名一个没有打开的 Session 时，不会让该 Session 继续执行未完成的工作，这样改名没有意外副作用。
29. 作为用户，我希望重命名一个已被其他进程占用的 Session 时看到“会话被占用”提示，这样知道为什么不能改名。
30. 作为用户，我希望归档后 Session 从侧栏和搜索中消失，这样可以清理列表而不丢数据。
31. 作为用户，我希望归档一个置顶 Session 时同时取消置顶，这样置顶分类里不会有隐藏的条目。
32. 作为用户，我希望执行中或等待确认的 Session 不能归档或永久删除，这样不会中断正在进行的工作。
33. 作为用户，我希望归档或永久删除当前打开的 Session 后回到首页新聊天，这样界面不会停留在一个不存在或已隐藏的 Session 上。
34. 作为用户，我希望永久删除前看到确认对话框，写明操作不可撤销，确认按钮为危险色，这样不会误删。
35. 作为用户，我希望永久删除会移除 Session 的 Transcript、子代理、附件与 file-history 备份，以及它的置顶和归档记录，这样删除是彻底的。
36. 作为用户，我希望点击新聊天右侧的搜索 icon 后出现 C25 搜索聊天浮层，输入框自动聚焦，占位符为“搜索聊天”，这样可以立刻输入。
37. 作为用户，我希望“聊天”分组列出所有未归档 Session，按更新时间排序，在浮层内滚动，而不是只显示 8 条，这样能找到较早的 Session。
38. 作为用户，我希望搜索同时匹配 Session Title 和 Project 名称，这样可以按项目查找。
39. 作为用户，我希望搜索结果右侧显示所属 Project 名称，不属于 Project 时留空，执行中的 Session 带加载 icon，这样能区分同名 Session。
40. 作为用户，我希望“快捷操作”分组提供新聊天和打开文件夹，这样搜索浮层也能作为快速入口。
41. 作为用户，我希望用方向键在搜索结果和快捷操作间移动，Enter 打开，Esc 关闭并把焦点还给搜索 icon，这样键盘可以完成搜索。
42. 作为用户，我希望搜索浮层打开和关闭时有缩放与淡入淡出，系统开启减少动态效果时直接切换，这样动效舒适又尊重系统设置。
43. 作为用户，我希望侧栏顶部的新聊天与搜索行在滚动时保持固定，其下分隔线仅在内容可滚动且已向下滚动时可见，回到顶部时隐藏，这样随时能新建或搜索。
44. 作为用户，我希望分类与 Session 在固定顶部之下一起滚动，分类标题不吸顶，这样与 C02 滚动稿一致。
45. 作为用户，我希望侧栏使用 A13 自定义滚动条，内容超出时才出现且不占布局宽度，这样侧栏宽度不会跳动。
46. 作为用户，我希望窄窗口下侧栏仍可使用、没有横向溢出，这样小窗口也能管理 Session。
47. 作为用户，我希望所有新文案在中文和英文界面都正确显示，这样切换语言后界面完整。
48. 作为键盘用户，我希望会话行、hover 操作、菜单项、弹窗和搜索浮层都有可见焦点和无障碍名称，这样不用鼠标也能完成全部操作。
49. 作为用户，我希望 Light 和 Dark 主题下侧栏、菜单、弹窗和浮层都符合 DESIGN.md 的对比度与 token，这样两种主题视觉一致。

## Implementation Decisions

### 侧栏分类与会话行

- 侧栏是 `@rukie/ui` 的 app component，Session 分组由一个纯函数从 Session 摘要、Project、置顶与归档集合推导：先排除 Archived Session；置顶集合内的 Session 归入“置顶”；其余按工作目录等于 Project 路径归入对应 Project，不匹配任何 Project 的归入“对话”。现有判断“对话”的 cwd 规则保持不变，Session 摘要不新增 Project 字段。
- 分类顺序为置顶、项目、对话，“最近”分区及其专用的 hover 操作移除。“置顶”在置顶集合与未归档 Session 的交集为空时不渲染。
- 分类标题沿用 `collapsedGroups` 偏好记录收起状态。侧栏选项菜单的“显示”勾选项改为置顶、项目、对话，旧的 `showConversations` 等偏好键按新的三类重新定义，不保留“最近”的偏好兼容。
- “展开显示”是会话侧栏的本地展开状态，阈值为 5：Project 列表和每个 Project 的 Session 列表各自截断，“对话”与“置顶”不截断。展开状态不持久化。
- 会话行由主按钮和行尾操作组成。行尾操作在 hover 或行内获得焦点时显示：置顶/取消置顶 icon 按钮和更多 icon 按钮。标题区域末尾使用渐隐遮罩，hover 时让出行尾操作宽度。执行中、等待确认指示和 Ctrl 序号提示保持现有行为。
- 侧栏滚动区改用现有 ScrollArea 和 A13 自定义滚动条。顶部新聊天与搜索行固定在滚动区外，分隔线仅在内容可滚动且已向下滚动时显示。侧栏宽度 268、标题栏、导航栏与对话区几何不变。

### 会话菜单

- 会话操作只有一份定义：重命名、置顶/取消置顶、归档、永久删除。每项声明图标、文案键、是否危险和是否可用。三个入口使用同一份定义：会话行右键菜单（beUI ContextMenu，锚定指针）、会话行更多菜单（shadcn DropdownMenu，与触发器末端对齐）、标题栏“会话更多”菜单（保留现有复制与打开方式）。
- 会话行菜单不展示快捷键。标题栏菜单中已有的置顶快捷键提示保持现状。
- 执行中或等待确认的 Session，其归档与永久删除项禁用。
- 菜单样式遵循 DESIGN.md 菜单规则与 C22：`menu` 面板、28px 行、危险项使用 destructive 色。

### 重命名

- 重命名弹窗按用户提供的截图实现：标题“重命名聊天”，副标题“保持简短且易于识别”，单行输入框，取消与保存按钮。英文为 “Rename chat” / “Keep it short and recognizable”。
- 提交前去掉首尾空白；为空或与原标题相同则保存按钮禁用。Enter 提交；Esc、关闭按钮和取消关闭弹窗。提交中禁用重复提交；失败时保留弹窗并显示用户可见错误。
- 新增 wire 命令 `session.rename { sessionId, title }`。服务端处理：
  - Session 已在本服务打开时，调用其现有 `rename`，Session Title 改为 user 来源，后续不再自动覆盖，并发出标题变更事件。
  - 未打开时，调用 Agent Core 新增的只写标题接口：只取得该 Session 的存储写入租约，写入会话元数据中的标题和 `title-source` Tool State 的 user 值后立即释放。该接口不创建 Session、不调度 Session Resume、不解析模型或凭据，并复用 Tool State 的版本与写入规则和 Session Title 的规范化规则。
  - 租约被占用时返回 `session_busy`，UI 显示“会话被占用”。
  - 成功后经 `sessions_changed` 推送新标题。
- 只写标题接口由 Agent Core 的 store 能力拥有，因为它拥有存储布局和写入租约；服务端只做路由。

### 归档

- 桌面端应用数据库的 registry 文档新增 `archived` Session id 列表，与 `pinned` 并列，属于 ADR-0035 所述的组织信息，不写入 Transcript。
- 新增 wire 命令 `session.archive { sessionId }`。服务端校验 Session 存在、未执行、无挂起交互；从 `pinned` 移除该 id 并加入 `archived`；保存后发出 `sessions_changed`，归档当前 Session 时携带 `closedSessionId`。`sessions_changed` 增加 `archived` 字段，store 校验并保存。
- `session.pin` 拒绝 Archived Session。本次不提供取消归档命令和入口。

### 永久删除

- 新增 wire 命令 `session.delete { sessionId }`。UI 先显示确认对话框（DESIGN.md 对话框规则，危险确认按钮），确认后才发送。
- 服务端拒绝执行中或有挂起交互的 Session；Session 在本服务打开且空闲时先关闭并释放租约。随后调用 Agent Core 新增的删除接口，从 `pinned` 与 `archived` 移除该 id，发出 `sessions_changed`，删除当前 Session 时携带 `closedSessionId`。
- 删除接口由 Agent Core 的 store 能力拥有：先取得写入租约，确认无其他宿主占用；删除该根 Session 的存储目录（包含共用存储的子代理）以及数据根下该 Session 的 `attachments/` 与 `file-history/` 目录；路径解析必须保持在数据根内。租约被占用时返回 `session_busy`，不删除任何文件。
- 删除后会话索引由下一次 `summaries()` 对账自然移除。

### 搜索聊天浮层

- 改造现有 CommandPalette 为 C25 搜索聊天浮层，不另写新组件：居中、宽 520、圆角 20、`popover` 面板，输入框自动聚焦，“聊天”与“快捷操作”两个分组，结果区使用 A13 自定义滚动条。
- “聊天”列出全部未归档 Session，按更新时间排序，不再限制空查询条数；匹配 Session Title 与 Project 名称；右侧显示 Project 名称，不属于 Project 时留空；执行中 Session 显示加载 icon。
- “快捷操作”只有新聊天和打开文件夹，后者等同现有添加项目。
- 打开与关闭使用缩放加淡入淡出；`prefers-reduced-motion` 下直接切换。关闭后焦点回到打开它的搜索 icon。
- C25 的 520 宽与 20 圆角超出 DESIGN.md 现有对话框尺寸。实现前先在 DESIGN.md 增加“搜索浮层”角色及其宽度、圆角与动效规则，再按规则实现。

### 文案与文档

- 新增或修改的文案同时更新 zh 与 en：重命名、归档、永久删除及其确认、重命名弹窗、会话被占用、搜索聊天、快捷操作、打开文件夹、展开显示、新建会话、添加项目等。移除不再使用的“最近”相关键。
- CONTEXT.md 已新增 Project 与 Archived Session 词条。
- DESIGN.md 补充搜索浮层角色；会话侧栏截断、行尾操作与菜单一致性规则写入 DESIGN.md 的侧栏部分。

## Testing Decisions

- 测试只验证公开行为：UI 用 Chromium browser 模式渲染 App 并通过 fake wire 观察命令与渲染结果；服务端通过 wire 命令与 `sessions_changed` 事件验证；Agent Core 通过公开的 store 接口和 `createSession` 验证存储结果。不断言内部状态或组件实现细节。
- 测试接缝，优先使用现有最高层接缝：
  1. UI app 层：现有 shell browser 测试和 fake wire 辅助。覆盖分类推导、置顶分类显隐、Session 唯一出现、截断与展开、hover/聚焦行尾操作、右键与更多菜单内容一致、菜单禁用状态、重命名弹窗交互与失败保留、删除确认、归档或删除当前 Session 后回到新聊天、搜索浮层分组、过滤、键盘导航与焦点恢复、减少动态效果。store 的 `sessions_changed` 解析（含 `archived`）放在现有 store Node 测试。
  2. 服务端 wire 层：现有 server 测试。覆盖 `session.rename` 对已打开与未打开 Session 的行为、未打开 Session 改名后不产生 Run 或任务恢复、`session_busy`；`session.archive` 的置顶移除、执行中拒绝和 `closedSessionId`；`session.delete` 的存储移除、置顶与归档清理、执行中拒绝和 `closedSessionId`；`session.pin` 拒绝 Archived Session。
  3. Agent Core store 层：新增的只写标题与删除接口。覆盖写入后经只读列表和 Session Resume 观察到 user 来源标题且不再被自动标题覆盖；租约占用时不写入或不删除；删除覆盖子代理、attachments 与 file-history，且不越出数据根。
- 布局保护：先按 DESIGN.md layout preservation gate 记录基线，在现有 layout browser 测试中补充侧栏固定顶部、滚动区高度受限、滚动后顶部保持固定、自定义滚动条不占宽度、窄窗口无横向溢出的几何断言，并重跑 shell、transcript、dock 与 composer 用例。
- 完成后按 AGENTS.md 进行一次 agent-browser GUI 验收：Light、Dark 与窄宽度截图，检查 cursor、hover、焦点和控制台错误。
- 参考已有测试：shell browser 中的侧栏偏好、搜索焦点恢复与运行状态用例；layout browser 中的 268px 侧栏几何用例；server 测试中的 pin、unpin 与 preferences 用例；store desktop 测试中的置顶分组用例。

## Out of Scope

- 取消归档与已归档列表入口。
- C22 中的标记为未读、分区、分享、复制、分叉、打开方式和在新窗口中打开。
- C25 中的“搜索文件”快捷操作。
