# 02: 帧差分：只写变化的 cell

**What to build:** 渲染器不再整屏重画，而是把新的 cell 网格和上一帧逐 cell 比较，只把变化的部分转成光标移动和 SGR 写出。对用户来说屏幕内容不变，但更新时不闪，写出的字节量也大幅减少。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 只改动一个字符的更新，写出的字节数明显少于整屏重画（测试里断言一个上限）
- [ ] 内容高度变矮时，多出来的旧行被清掉
