# 05：自动保存、服务开关、预设目录与协议联动

Status: ready-for-agent

Blocked by: 01, 02, 03, 04

**What to build:** 按 [spec 界面流程](../spec.md#界面流程)把供应商表单改为自动保存，删除输入校验，接入预设目录（P02 / L-P02）与新建服务的协议联动。

- [ ] 添加供应商目录：依次显示"创建自定义供应商"与 `PROVIDER_PRESETS` 卡片，使用 `ProviderIcon` 的 Color 变体；卡片可用键盘操作，有可访问名称和焦点样式
- [ ] 点击预设：立即保存服务（id 为 `deepseek`、`deepseek-2`…，名称为"DeepSeek"、"DeepSeek 2"…，`defaultApi` 变体，带 `icon`，`enabled: true`），然后选中该服务；"创建自定义供应商"同样立即保存
- [ ] 协议联动：来源预设记在组件内存中，当前表单是新建服务时，切换 API 格式会替换为该变体的 Base URL 与模型并保存；切走或卸载后清除
- [ ] 自动保存：Base URL 与 API Key 停止输入 500ms 后保存；切换服务、离开设置页、卸载时立即保存未保存的输入；开关、API 格式、模型增删、启停和编辑立即保存；保存请求串行执行，后到的修改不被先返回的结果覆盖
- [ ] 删除表单底部的保存和取消按钮、`dirty` 分支、"已保存"状态，以及 `services.invalid` 与 `services.apiIncompatible` 的前置校验和文案；读取、保存、显示 Key、测试失败的提示保留，保存失败时保留输入
- [ ] 服务开关读写 `enabled`，没有模型时也可以操作，停用不修改模型的 `enabled`
- [ ] zh 和 en 文案同步增删
- [ ] 测试（Chromium，脚本化 host，防抖使用虚拟时钟）：预设创建与 id、名称递增；协议联动与切走后不联动；在 499ms 和 500ms 两个时刻验证防抖边界；切换服务和卸载时立即保存；连续修改的保存顺序；没有保存按钮也没有校验提示；保存失败时保留输入；开关在没有模型时可操作并保留模型状态；取消或关闭弹窗不保存
