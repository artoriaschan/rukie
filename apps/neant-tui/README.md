# Neant TUI

交互式 `neant` 在全屏终端中显示 Transcript，输入及状态栏固定在底部。启动方式和模型配置见[架构](../../docs/architecture.md)。非交互输入使用 Headless CLI。

## 后台任务

bash 显式后台启动或超时转后台后，发起它的工具卡下显示 JobCard：命令、状态和最近两行视觉输出。输出随 Session 事件更新，使用 frontend 独立游标，不影响模型的 `job_output`。连续两张及以上 JobCard 合组；全部结束后折叠为状态摘要，Ctrl+O 或点击组标题展开，审批、提问和其他模态界面接管时不切换分组。

`/jobs` 在空闲或 Run 中打开当前 Session 的整屏后台任务列表，已结束任务仍可查看；点击单张或分组中的 JobCard 会聚焦对应任务。↑/↓ 选择，`e` 展开命令、启动/转后台/结束时间、退出码、输出文件和有界输出尾部，PageUp/PageDown 或滚轮浏览详情；早期输出丢弃时提示查看输出文件。转后台时间是 frontend 首次观察到任务进入后台的时间，结合发起 bash 的参数区分显式启动与超时转后台。

`k` 首次准备停止所选任务，4 秒内再次按 `k` 才调用 Session 停止它；导航、其他按键或窗口到期取消准备，已结束任务不能停止。停止中状态立即显示；空闲时停止不自动调用模型，停止消息随下一条用户输入交给模型。Esc 或 Ctrl+C 返回 chat，草稿、阅读内容锚点与底部跟随状态保留，Run 和待处理 Interaction 继续。面板支持 40×12 及 resize；任务组在面板打开期间仍按原规则结束折叠。

状态栏的 `● N` 统计运行中及停止中的任务；悬停显示 label 和时长，Session 空闲时仍更新。任务结束显示对应完成、失败或停止通知，最新通知保留约 6 秒并限制为一行，其他通知保持原有生命周期。任务仅在当前 Session 进程中存在，恢复 Transcript 不显示历史任务卡；Rewind 和 compaction 保留当前任务。

## 上下文报告

`/context` 在消息区显示当前上下文的静态快照：容量网格、模型名称与 ID、总用量、分类估算，以及 MCP 工具、子代理类型、指令文件与 Skill 的数量和 token 摘要。`/context all` 同时展开逐项明细。两种命令在 Run 中也可用，不调用模型、不写入 Transcript；后续响应不会改变已有快照。总用量优先使用 provider 报告，分类保留估算值，压缩预留使用模型窗口的 20%。

命令行采用普通用户消息的主题色、加粗和悬挂缩进，不添加背景色。宽终端将网格和图例并排，空间不足时上下排列；小于 80 列使用缩小网格。资源摘要始终放在网格和图例下方。界面保留启动时的中英文 locale。

## 输入提示

输入框右侧 Tips 共用 10 秒自动隐藏时间。提示内容出现或变化时重新计时，重复相同内容、编辑草稿或普通重绘不会延长显示；来源清除时立即隐藏。通知优先显示且保留各自的时长，覆盖 Tips 时 Tips 的计时继续。回退准备提示受原有 3 秒操作窗口限制，窗口结束会提前消失。隐藏 Tips 不移动输入框或光标，也不修改草稿。

空闲且输入为空时，首次 Esc 显示「再按一次 Esc 回退」，3 秒内再次按 Esc 打开 Rewind；`/rewind` 直接打开。当前 Session 无 Checkpoint 时，右侧 Tips 显示「还没有可回退的消息」（英文「Nothing to rewind yet」），沿用 10 秒生命周期，不打开选择器、不进入消息流或 Transcript。编辑草稿不会清除提示，重复相同提示不延长显示；提交真实用户消息后清除提示，新 Session 不继承提示。

空闲且输入为空时，首次 Ctrl+C 显示「再次按 Ctrl+C 退出」（英文「Press Ctrl+C again to exit」），优先于回退和剪贴板 Tips。1 秒内再次连续按 Ctrl+C 退出；窗口到期或其他操作取消退出准备时，提示立即清除。运行中的 Ctrl+C 仍中断 Run，有草稿时仍清空草稿，这两种情况不提示再次退出。

## MCP 管理与授权

`/mcp` 打开本地管理面板，可在 Run 中浏览。首次读取自动从 loading 转入服务器列表，按项目、用户来源分组；选择服务器进入详情，再进入工具列表与工具详情。详情显示生效配置、连接状态、授权方式与错误；工具详情显示完整描述和输入 JSON Schema，浏览不执行工具或调用模型。配置文件读取失败保留诊断与重试入口，其他合法服务器继续可用。

列表用 ↑/↓ 循环选择，Enter 或鼠标单击进入；hover 只显示背景，滚轮移动选择并保持选中行可见。服务器详情用 Tab 在正文与动作间切换焦点；正文用 ↑/↓、PageUp/PageDown 或正文区域滚轮阅读，动作用 ↑/↓、Enter 或鼠标单击执行。工具详情使用相同阅读按键。Esc 或返回逐层回退并恢复各页选择、焦点与阅读位置，服务器列表的 Esc 关闭面板。面板最多14行，标题与提示固定；40×12时与 Todo、Subagent、Goal 预览共存，小于40×12暂停交互，resize后恢复有效位置。Ctrl+C 在空闲时关闭面板，在 Run 中中断并关闭；退出仍恢复终端。

所有页面显示时主输入框锁定，字符、提交、历史、Tab 补全、文本及图片粘贴不能修改草稿、光标或附件。打开面板使已开始的主输入粘贴和图片读取失效，即使关闭后结果才返回也不写回。关闭后恢复编辑；接受 `/mcp` 命令时仍按通常规则清理命令并记录输入历史。授权、审批与问题的 Interaction FIFO 临时接管键盘和鼠标，队列结束后恢复 MCP 页面，授权自己的回调 URL 输入保持可用。

详情提供查看工具、登录、登出、重连与返回。管理操作只在空闲时可用，Run 中显示 busy；处理中禁止重复提交，完成后留在详情并显示成功、失败或取消结果。配置读取重试重新读取并探测完整配置；普通浏览只读 Agent Core 已提交的快照。Core 事件实时更新列表与详情，按服务器名和协议工具名保留有效身份；工具消失退回工具列表，最后工具消失退回服务器详情，服务器消失退回服务器列表，显示变化提示并保留有效上级的阅读位置。管理面板与结果不进入模型上下文、Transcript 或 Tool State，Resume、换 Session 与退出均清理本地面板。

空闲时也可以用 `/mcp login <server>`、`/mcp logout <server>`、`/mcp reconnect <server>` 登录、删除该服务器的凭据或重新探测。登录复用下方授权面板，动作完成后显示结果通知；Run 中的管理子命令提示稍后再用。输入 `/mcp ` 可补全子命令，第二层服务器名来自最近一次读取的状态；Tab 补全草稿，Enter 或鼠标选择完整服务器命令执行。

MCP 服务器需要授权时，输入框显示一次提示。同一个 Session 内，每个服务器只提示一次；配置和凭据规则见 [MCP](../../docs/mcp.md)。模型调用服务器的 `authenticate` 工具后，授权面板与审批、提问共用 FIFO 队列；轮到该面板显示时，TUI 自动打开系统浏览器。

面板显示服务器名称、完整授权 URL、复制链接、重新打开浏览器和取消登录选项。复制或重开只更新面板内的反馈；浏览器打开失败时，面板提供手动打开引导。可以粘贴完整回调 URL 后按 Enter，也可以等待本地回调自动完成。Esc 或取消登录关闭面板，Run 中断也会关闭面板。40×12 终端中 URL 换行，PageUp / PageDown 滚动引导与 URL，动作和回调输入栏保留在面板中。

授权成功显示绿色通知 4 秒，失败显示错误通知 8 秒，取消显示弱化通知 4 秒。授权面板沿用启动时的中英文 locale，显示期间隐藏活动动画。

## 消息中的图片

剪贴板包含图片或 Finder 复制的图片文件时，输入框右下角 Tips 显示「剪贴板中有图片 · ctrl+v 粘贴」；英文为「Image in clipboard · ctrl+v to paste」。提示按 locale 切换，沿用[输入提示](#输入提示)的自动隐藏时间；剪贴板持续有图时，后续轮询不会重新显示已过期提示。每次格式探测完成后一秒再次检查，剪贴板变为非图片或不可用时清除，再次检测到图片可重新提示。探测不导出或解码图片；Ctrl+V 仍通过现有粘贴入口读取并暂存。粘贴结果通知和回退提示优先显示；选择器、审批及图片预览接管输入时暂停图片提示。小窗口按现有规则暂停编辑。Windows 剪贴板目前只支持文本，不显示图片提示。

用户消息、`read` 图片结果及恢复的 Transcript 使用同一画廊。单张缩略图最多 24×12 个终端 cell，多张使用 10×5 的格子并随宽度换行。支持 Kitty graphics 的终端显示 PNG；tmux、screen、未支持图形协议的终端和其他格式保留可点击的文字及相同格子空间。窗口小于 40×12 时暂停图形显示。

点击缩略图或文字打开消息区域内的图片预览，输入草稿及阅读位置保留，后台 Run 继续。预览显示格式、像素尺寸、原始字节大小和名称，并在打开时快照当前 Transcript 的全部图片；同一图片多次出现仍分别计数，后台新增图片不会改变已打开的画廊。左右键和 ‹/› 切换图片，在边界停止。

支持 PNG 图形且终端提供 cell 像素尺寸时，100%、+/- 可在 1×、2×、4×、8× 间检查原始像素区域；四向按钮、拖动图片和滚轮平移裁剪区域。Fit 恢复等比例全图。缺少图形支持或 cell 像素尺寸时禁用缩放和平移，仍可查看元数据及使用 Fit。终端选择缩放过滤方式。

Esc、Ctrl+C、Enter 或点击消息区域中卡片外的位置关闭预览，关闭按键不会提交草稿或中断 Run。预览期间消息缩略图保留布局并暂停图形显示。审批、提问、计划评审、新 Session 及 conversation Rewind 接管时关闭预览。

只有卡片底部的“打开原图”调用系统查看器。正在打开时再次点击不会重复启动；失败显示原因，可以再点击重试。原始文件通过现有 frontend host 导出到私有临时目录，关闭 TUI 时等待正在进行的打开操作结束后清理；消息点击本身不会启动外部应用。名称是经过控制字符过滤和宽度限制的显示数据。
