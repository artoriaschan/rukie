# Neant TUI

交互式 `neant` 在全屏终端中显示 Transcript，输入及状态栏固定在底部。启动方式和模型配置见[架构](../../docs/architecture.md)。非交互输入使用 Headless CLI。

## 会话正文

用户消息使用金色加粗 `❯` 和悬挂缩进，不填充背景；assistant 的正文标记使用普通文字色。正文通过 `@neant/tui` 的 Markdown 呈现段落、标题、列表、引用、代码框、GFM 表格与任务项、Unicode 数学公式及 Mermaid 图。未闭合的代码 fence 仍保持代码块；数学公式未闭合、不支持、超过长度或宽度限制时保留原始源文，Mermaid 无法绘制或超过可用宽度时保留代码。正文没有整段折叠点击动作。 会话正文支持鼠标拖动选字，松开后通过 host 剪贴板复制并清除高亮；复制实际绘制的文字，排除消息标记与代码框装饰，软换行还原为同一行。剪贴板不可用会明确提示，流式替换所选内容时拒绝复制并提示重新选择。拖动不触发卡片或路径点击；滚轮和自动跟随平移选区两端，并保留移出屏幕的已绘制文本；再次移动指针才延长选区，完全移出同一边界时松开丢弃。resize、Esc 及 Session 切换清理选区，旧 Session 的复制结果不显示在新会话。

实时正文及刚完成的一次性回复按共享的约 30fps 节拍显示，每帧推进至少三个 UTF-16 单位并按剩余内容自适应追赶；不拆开 surrogate pair。Run 结束后已经创建的游标继续追赶尾部；内容替换立即显示。一个消息身份首次追赶完成后，后续增长直接显示，不重启动画；这一规则沿用固定 dsh-TUI 参考。Session Resume 直接显示完整历史，切换 Session 重建显示状态。显示节奏不改变 Session 事件、模型上下文或 Transcript。

## 中断与恢复

用户中断或 provider 错误保留已提交的部分正文与思考，并显示结束原因。Session Resume 按保存顺序重建正文、工具、已回答问题、Todo 与子代理事实；思考与工具采用默认折叠，正文立即显示。界面展开、选区、悬停、消息选择、阅读位置与 Tool View 不写入 Transcript。

保存失败时，实时会话以 Agent Core 恢复的已提交事实收束，未保存的临时尾部消失。已保存调用缺少结果时显示 Outcome unknown；副作用可能已经发生，用户应核实实际状态后再决定是否重试。查看恢复历史不执行工具、不重新启动 Background Job 或自动续跑 Subagent；完整工具源或历史元数据缺失时保留相应未知说明。后台任务与只读子代理的操作见各自章节。

## 消息导航

Shift+↑ 从最后一条普通消息进入选择；↑/← 和 ↓/→ 移动，Enter 只展开所选思考、工具或计划卡，Esc 返回草稿。普通正文 Enter 不提交输入；Background Job 和 Subagent 保留各自入口。当前卡片用浅色背景标明，选择与点击展开共享单卡状态，Ctrl+O 继续控制全局详情。Interaction、工具窗口和已有面板优先接管按键；选字手势中的 Shift+方向键仍延长选区。 父级审批、提问和计划评审到来时临时接管已经打开的 Agent View、子代理详情、任务列表、dashboard 或设置页面；原页面身份与阅读源保留，回答或取消后恢复。请求期间箭头、Enter、Esc 属于 Interaction，小终端仍暂停回答并允许中断或退出。临时接管也保留工具卡的展开和当前源窗口；请求结束后窗口键盘焦点需重新选择，正常关闭页面及 Session 更换使用默认状态。

至少两条真实用户输入、正文可滚动且宽度至少 60 列时，右侧两列时间线定位各输入。上下箭头寻找当前视口上方或可达的下方输入；横线点击跳到对应输入。悬停 120ms 后预览首个非空行，最多两行；滚动、resize、页面或 Session 更换清除预览。向上阅读时固定一行提示当前输入，点击提示回到该输入；时间线、预览和固定提示不进入正文复制。

向上阅读暂停跟随，新内容保留原阅读源并提示回底。Enter 或 End 先回到底部，随后 Enter 才提交已有草稿；Ctrl+End 仍可立即回底。展开、收束、后台更新和 resize 使用消息身份与文本偏移保留位置，正在阅读的详情消失时回到所属卡片。Session 切换及恢复使用默认选择、展开与跟随状态；小终端退出消息选择，保留既有中断和退出能力。

## 后台任务

bash 显式后台启动或超时转后台后，以 JobCard 显示真实 ID、命令、状态、耗时和最近两行视觉输出。命令默认一行，点击命令独立展开；标题点击打开对应任务详情。输出随 Session 事件更新，使用 frontend 独立游标，不影响模型的 `job_output`。连续两张及以上 JobCard 合组并显示分组轨；至少三张全部结束后默认折叠为状态摘要，失败和终止计数仍可见。点击组标题独立折叠或展开该组，Ctrl+O 展开全部，审批、提问和其他模态界面接管时不切换分组。拖选复制保留命令和输出文字，排除命令、输出边框及分组轨。

`/jobs` 在空闲或 Run 中打开当前 Session 的整屏后台任务列表，已结束任务仍可查看；点击单张或分组中的 JobCard 标题会聚焦对应任务并直接展开详情。↑/↓ 选择，`e` 展开命令、启动/转后台/结束时间、退出码、终止信号、输出文件和有界输出尾部，PageUp/PageDown 或滚轮浏览详情；早期输出丢弃时提示查看输出文件。转后台时间是 frontend 首次观察到任务进入后台的时间，结合发起 bash 的参数区分显式启动与超时转后台。

`k` 首次准备停止所选任务，4 秒内再次按 `k` 才调用 Session 停止它；导航、其他按键或窗口到期取消准备，已结束任务不能停止。停止中状态立即显示；空闲时停止不自动调用模型，停止消息随下一条用户输入交给模型。Esc 或 Ctrl+C 返回 chat，草稿、阅读内容锚点与底部跟随状态保留，Run 和待处理 Interaction 继续。面板支持 40×12 及 resize；任务组在面板打开期间仍按原规则结束折叠。

状态栏的 `● N` 统计运行中及停止中的任务；悬停显示 label 和时长，Session 空闲时仍更新。任务结束显示对应完成、失败或停止通知，最新通知保留约 6 秒并限制为一行，其他通知保持原有生命周期。任务仅在当前 Session 进程中存在，恢复 Transcript 不显示历史任务卡；Rewind 和 compaction 保留当前任务。

## 上下文报告

`/context` 在消息区显示当前上下文的静态快照：容量网格、模型名称与 ID、总用量、分类估算，以及 MCP 工具、子代理类型、指令文件与 Skill 的数量和 token 摘要。`/context all` 同时展开逐项明细。两种命令在 Run 中也可用，不调用模型、不写入 Transcript；后续响应不会改变已有快照。总用量优先使用 provider 报告，分类保留估算值，压缩预留使用模型窗口的 20%。

命令行采用普通用户消息的主题色、加粗和悬挂缩进，不添加背景色。宽终端将网格和图例并排，空间不足时上下排列；小于 80 列使用缩小网格。资源摘要始终放在网格和图例下方。界面保留启动时的中英文 locale。

## 输入提示

输入框右侧 Tips 共用 10 秒自动隐藏时间。提示内容出现或变化时重新计时，重复相同内容、编辑草稿或普通重绘不会延长显示；来源清除时立即隐藏。通知优先显示且保留各自的时长，覆盖 Tips 时 Tips 的计时继续。回退准备提示受原有 3 秒操作窗口限制，窗口结束会提前消失。隐藏 Tips 不移动输入框或光标，也不修改草稿。

空闲且输入为空时，首次 Esc 显示「再按一次 Esc 回退」，3 秒内再次按 Esc 打开 Rewind；`/rewind` 直接打开。当前 Session 无 Checkpoint 时，右侧 Tips 显示「还没有可回退的消息」（英文「Nothing to rewind yet」），沿用 10 秒生命周期，不打开选择器、不进入消息流或 Transcript。编辑草稿不会清除提示，重复相同提示不延长显示；提交真实用户消息后清除提示，新 Session 不继承提示。

空闲且输入为空时，首次 Ctrl+C 显示「再次按 Ctrl+C 退出」（英文「Press Ctrl+C again to exit」），优先于回退和剪贴板 Tips。1 秒内再次连续按 Ctrl+C 退出；窗口到期或其他操作取消退出准备时，提示立即清除。运行中的 Ctrl+C 仍中断 Run，有草稿时仍清空草稿，这两种情况不提示再次退出。

## MCP 管理与授权

`/mcp` 打开本地管理面板，可在 Run 中浏览。首次读取自动从 loading 转入服务器列表，按项目、用户来源分组；选择服务器进入详情，再进入工具列表与工具详情。详情显示生效配置、连接状态、授权方式与错误；工具详情显示完整描述和输入 JSON Schema，浏览不执行工具或调用模型。配置文件读取失败保留诊断与重试入口，其他合法服务器继续可用。

列表用 ↑/↓ 循环选择，Enter 或鼠标单击进入；hover 只显示背景，滚轮移动选择并保持选中行可见。服务器详情用 Tab 在正文与动作间切换焦点；正文用 ↑/↓、PageUp/PageDown 或正文区域滚轮阅读，动作用 ↑/↓、Enter 或鼠标单击执行。工具详情使用相同阅读按键。Esc 或返回逐层回退并恢复各页选择、焦点与阅读位置，服务器列表的 Esc 关闭面板。面板最多14行，标题与提示固定；40×12时与 Todo、Subagent、Goal 预览共存，小于40×12暂停交互，resize后恢复有效位置。Ctrl+C 在空闲时关闭面板，在 Run 中中断并关闭；退出仍恢复终端。

所有页面显示时主输入框锁定，字符、提交、历史、Tab 补全、文本及图片粘贴不能修改草稿、光标或附件。打开面板使已开始的主输入粘贴和图片读取失效，即使关闭后结果才返回也不写回。关闭后恢复编辑；接受 `/mcp` 命令时仍按通常规则清理命令并记录输入历史。授权、审批与问题的 Interaction FIFO 临时接管键盘和鼠标，队列结束后恢复 MCP 页面，授权自己的回调 URL 输入保持可用。

详情提供查看工具、登录、登出、重连与返回。管理操作只在空闲时可用，Run 中显示 busy；处理中禁止重复提交，完成后留在详情并显示成功、失败或取消结果。配置读取重试重新读取并探测完整配置；普通浏览只读 Agent Core 已提交的快照。Core 事件实时更新列表与详情，按服务器名和协议工具名保留有效身份；工具消失退回工具列表，最后工具消失退回服务器详情，服务器消失退回服务器列表，显示变化提示并保留有效上级的阅读位置。管理面板与结果不进入模型上下文、Transcript 或 Tool State，Resume、换 Session 与退出均清理本地面板。

空闲时也可以用 `/mcp login <server>`、`/mcp logout <server>`、`/mcp reconnect <server>` 登录、删除该服务器的凭据或重新探测。登录复用下方授权面板，动作完成后显示结果通知；Run 中的管理子命令提示稍后再用。输入 `/mcp ` 可补全子命令，第二层服务器名来自最近一次读取的状态；Tab 补全草稿，Enter 或鼠标选择完整服务器命令执行。

MCP 服务器需要授权时，输入框显示一次提示。同一个 Session 内，每个服务器只提示一次；配置和凭据规则见 [MCP](../../docs/mcp.md)。模型调用服务器的 `authenticate` 工具后，授权面板与审批、提问共用 FIFO 队列；轮到该面板显示时，TUI 自动打开系统浏览器。

面板显示服务器名称、完整授权 URL、复制链接、重新打开浏览器和取消登录选项。复制或重开只更新面板内的反馈；浏览器打开失败时，面板提供手动打开引导。可以粘贴完整回调 URL 后按 Enter，也可以等待本地回调自动完成。Esc 或取消登录关闭面板，Run 中断也会关闭面板。40×12 终端中 URL 换行，PageUp / PageDown 滚动引导与 URL，动作和回调输入栏保留在面板中。

授权成功显示绿色通知 4 秒，失败显示错误通知 8 秒，取消显示弱化通知 4 秒。授权面板沿用启动时的中英文 locale，显示期间隐藏活动动画。

## 输入框图片预览

粘贴图片后，点击绑定的 `[Image #N]` 会打开消息流同款预览弹窗，并反色高亮当前图片对应的 token。弹窗使用当前草稿的绑定图片快照，支持左右翻页、Fit、缩放/平移与打开原图，沿用消息流预览的图形支持条件和消息区布局。弹窗接管输入；Esc、Ctrl+C、Enter 或点击消息区空白关闭弹窗，不提交草稿或中止 Run。关闭后草稿保留，再次点击可重开；普通文字和手打 token 不可点击预览。

仅将光标移到绑定 token 起始位置时，显示单图被动卡并反色高亮；token 末尾不算命中。被动卡没有翻页、缩放或打开原图控件，输入框继续接收移动、打字与提交，发送时仍附带图片。首次 Esc 只关掉当前卡，光标离开后再回来或移到另一绑定 token 时重新显示。删除 token、清空或提交草稿会移除被动卡；无图形支持时显示文字占位与元数据。

终端小于 40×12、待处理 Interaction、非 chat 视图、模型或 Session 选择器、Rewind、MCP 面板、文件操作菜单及 transcript 模式显示时隐藏光标预览；恢复编辑且光标仍命中绑定 token 时重新显示。消息缩略图打开的模态预览优先，关闭后恢复光标预览。

## 消息中的图片

剪贴板包含图片或 Finder 复制的图片文件时，输入框右下角 Tips 显示「剪贴板中有图片 · ctrl+v 粘贴」；英文为「Image in clipboard · ctrl+v to paste」。提示按 locale 切换，沿用[输入提示](#输入提示)的自动隐藏时间；剪贴板持续有图时，后续轮询不会重新显示已过期提示。每次格式探测完成后一秒再次检查，剪贴板变为非图片或不可用时清除，再次检测到图片可重新提示。探测不导出或解码图片；Ctrl+V 仍通过现有粘贴入口读取并暂存。粘贴结果通知和回退提示优先显示；选择器、审批及图片预览接管输入时暂停图片提示。小窗口按现有规则暂停编辑。Windows 剪贴板目前只支持文本，不显示图片提示。

用户消息、`read` 图片结果及恢复的 Transcript 使用同一画廊。单张缩略图最多 24×12 个终端 cell，多张使用 10×5 的格子并随宽度换行。支持 Kitty graphics 的终端显示 PNG；tmux、screen、未支持图形协议的终端和其他格式保留可点击的文字及相同格子空间。窗口小于 40×12 时暂停图形显示。

点击缩略图或文字打开消息区域内的图片预览，输入草稿及阅读位置保留，后台 Run 继续。预览显示格式、像素尺寸、原始字节大小和名称，并在打开时快照当前 Transcript 的全部图片；同一图片多次出现仍分别计数，后台新增图片不会改变已打开的画廊。左右键和 ‹/› 切换图片，在边界停止。

支持 PNG 图形且终端提供 cell 像素尺寸时，100%、+/- 可在 1×、2×、4×、8× 间检查原始像素区域；四向按钮、拖动图片和滚轮平移裁剪区域。Fit 恢复等比例全图。缺少图形支持或 cell 像素尺寸时禁用缩放和平移，仍可查看元数据及使用 Fit。终端选择缩放过滤方式。图片可绘制时不显示降级提示，透明区域保持干净；仅无法绘制时显示文字占位。

Esc、Ctrl+C、Enter 或点击消息区域中卡片外的位置关闭预览，关闭按键不会提交草稿或中断 Run。预览期间消息缩略图保留布局并暂停图形显示。审批、提问、计划评审、新 Session 及 conversation Rewind 接管时关闭预览。

只有卡片底部的“打开原图”调用系统查看器。正在打开时再次点击不会重复启动；失败显示原因，可以再点击重试。原始文件通过现有 frontend host 导出到私有临时目录，关闭 TUI 时等待正在进行的打开操作结束后清理；消息点击本身不会启动外部应用。名称是经过控制字符过滤和宽度限制的显示数据。

## 工具卡与 transcript 模式

工具卡按 Tool View 显示命令、文件内容、搜索匹配、网页 Markdown 或 diff。完成卡片只在开始与结束时刻可用时显示耗时，失败显示红色 `✗`，未知结果显示 `?`；前台 bash 的非零退出码与信号独立于正文折叠。文本默认显示 3 个逻辑行，diff 显示 8 个逻辑行；只多一行时完整显示，尾部空白不增加预算，长行按终端宽度换行，折叠预览每个逻辑行最多 1000 个 UTF-16 单元且不拆开代理对，隐藏字符数独立提示。点击卡片内容切换单卡展开，空白单元格不触发切换；展开窗口最多显示 400 行并说明当前范围。Previous/Next 控件继续浏览保留源；点击窗口控件后方向键逐行、PageUp/PageDown 每次 400 行、Home/End 到首尾窗口，Esc 释放窗口键盘焦点。其他输入、拖选或滚动释放焦点，恢复全局阅读与输入。状态、箭头和 gutter 不进入复制内容。悬停卡片在标题末尾显示展开方向并提亮提示，状态标记保持可见。

Ctrl+O 切换 transcript 模式，同时展开工具卡、thinking 和后台任务组；单卡展开与全局展开取并集。Run 中也可切换，Interaction、侧问、图片预览或文件菜单接管输入时忽略该快捷键。展开与折叠保留阅读位置及底部跟随。Todo 成功只更新面板，问题、计划评审与子代理使用专用记录；Todo 失败仍显示错误卡。

卡片标题及 diff 中带下划线的路径可点击打开文件菜单，路径按 Session 工作目录解析。菜单按实际文件类型显示打开文件或打开文件夹，并提供在文件管理器中显示和复制绝对路径，支持键盘、鼠标与 Esc 关闭；动作失败或剪贴板不可用时显示提示。路径点击不改变卡片展开状态。

## 工具标题

工具参数 JSON 最多显示 480 个字符。多行前台命令默认显示首个非空行和 `+N 行`；用户 `~/.neant/settings.json` 中的 `foldTerminalCommand: false` 保留所有命令行。该设置只控制标题，不改变执行内容或正文折叠。命令标题按终端宽度换行，折叠状态每个逻辑行最多保留 1000 个 UTF-16 单位，不拆开 surrogate pair，并披露隐藏字符数；单卡展开或 Ctrl+O 显示完整命令。文件标题采用工具名与路径，保留路径独立点击入口。

标题确有隐藏内容（参数裁剪、脚本折叠、长命令裁剪或非命令标题宽度裁剪）时，悬停 600 ms 显示完整标题、开始 / 结束时刻，以及可用的退出码 / 信号；tooltip 不重复耗时。移开、按键、点击、滚轮、失焦、resize、打开交互或切换页面会清除 tooltip。小终端按可用空间换行与裁剪，浮层不会改变 Transcript 阅读位置。

## 工具 diff 布局

读文件、终端、网页或搜索结果截断时，完整源不可用提示显示在折叠与窗口之外；读文件续读 offset、终端恢复路径与执行状态同样独立显示。patch-only diff 只保留变更片段，片段外源不可用提示不会被折叠隐藏。Session Resume 从保存的事实重建相同披露，窗口范围仅描述保留源。

用户在 `~/.neant/settings.json` 设置 `diffLayout` 为 `auto`、`unified` 或 `split`。默认 `auto` 在终端宽度至少 110 列时使用左右分栏，窄于 110 列时使用 unified，resize 后即时切换。显式值固定布局，包括小终端上的 `split`；分栏长行截断，两栏保持逐行对齐。diff 默认折叠到 8 个呈现行，点击单卡或 Ctrl+O 展开；展开最多显示 400 个对齐行，窗口控件可继续浏览；范围说明区分对齐行与保留的 diff 源行总数，resize 用源行身份恢复位置。设置由启动时加载，Session Resume 与子代理详情使用同一布局选择。

工具调用的 pending diff 按共享的约 30fps 节拍逐行出现，每帧推进至少 3 行并按 backlog 自适应追赶。结果、错误、恢复卡片和展开窗口立即显示。已经追赶完成或展开过的调用再次折叠时不会重启动画；Session 更换和界面关闭会释放其 reveal 订阅，所有调用都追赶完成时停止共享定时器。

Ctrl+O 展开整段对话后，按 `/` 输入搜索词，Enter 高亮并跳到首个匹配；`n` / `N` 在全部匹配间循环前进 / 后退，无结果时显示提示。搜索包含已保留的工具源与思考文本，超过 400 行的工具卡会移动显示窗口到当前匹配。Run 进行中也可搜索；Esc 或 Ctrl+O 退出展开模式，保留输入草稿与当前阅读位置，恢复普通斜杠命令补全。

会话选字还支持双击选 Unicode 单词或路径、三击选显示行，再拖动扩展整词或整行；连续按下间隔严格小于 500ms 且横纵距离各不超过一个单元格。修饰键鼠标按下重置连击，使用字符选择。鼠标手势保持期间，Shift+方向键/Home/End 延长同一文本选区，松开鼠标统一校验并复制；没有文本手势时按键交给输入框和消息导航，审批及模态面板优先。

默认 host 根据平台调用 pbcopy、clip.exe 或 wl-copy/xclip/xsel，等待真实退出结果，每个 helper 最多 2000ms。`SSH_CONNECTION` 存在时跳过远端原生剪贴板，单独的旧 `SSH_TTY` 不阻止本地复制。tmux 使用 load-buffer（iTerm2 避免 `-w`）并在成功时发送 DCS 包装的 OSC52；失败使用原始 OSC52。Kitty 使用 ST，其他终端使用 BEL，screen 使用 DCS 包装；不修改 tmux 配置。`writeClipboard` 的 true 表示原生 helper 或 tmux buffer 成功，false 表示失败，`sent` 表示向终端提交了无确认的 OSC52；后者明确提示“已向终端发送剪贴板请求”，不能确认终端实际接受。默认 host 通过 main 的环境及 stdout 终端 transport 注入，关闭后取消未完成 helper 并停止输出。

## Subagent 观察

运行卡保留当前工具和三行截断输出；正常结束收起，错误原因保留。标题展示实际模型、可获得的耗时和 token，历史缺失字段不显示。Run Outcome 与当前活动分别处理，Run 正常结束不宣称委派任务完成。

点击卡片文字打开摘要、正文和工具详情；右侧 `⤢` 独立打开主屏 Agent View。Agent View 按真实子 Session 消息顺序展示输入、Markdown、可展开思考和复用的 ToolCall，键盘与粘贴输入不能提交 Run，也不能中断子代理。↑↓、PageUp/PageDown、Home/End 与滚轮用于阅读，Esc/Ctrl+C 返回父视图并恢复阅读位置与草稿。手动离开底部后新输出保持阅读位置；恢复后首次打开从只读快照加载历史，不自动续跑。子 Session 保存失败时，已打开的 Agent View 和卡片也重新读取已提交分支，保留已保存部分与未知工具结果，移除未保存尾部；之后的新 Run 不受较早只读请求影响。

子代理正文在实时观察与恢复后都保留实际用户输入，按已完成消息顺序显示一次；带有内部 `source` 的提醒消息不作为用户输入呈现。卡片的三行预览仍显示子代理输出。
