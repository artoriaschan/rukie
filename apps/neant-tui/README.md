# Neant TUI

交互式 `neant` 在全屏终端中显示 Transcript，输入及状态栏固定在底部。启动方式和模型配置见[架构](../../docs/architecture.md)。非交互输入使用 Headless CLI。

## 上下文报告

`/context` 在消息区显示当前上下文的静态快照：容量网格、模型名称与 ID、总用量、分类估算，以及 MCP 工具、子代理类型、指令文件与 Skill 的数量和 token 摘要。`/context all` 同时展开逐项明细。两种命令在 Run 中也可用，不调用模型、不写入 Transcript；后续响应不会改变已有快照。总用量优先使用 provider 报告，分类保留估算值，压缩预留使用模型窗口的 20%。

宽终端将网格和图例并排，空间不足时上下排列；小于 80 列使用缩小网格。资源摘要始终放在网格和图例下方。界面保留启动时的中英文 locale。

## 消息中的图片

用户消息、`read` 图片结果及恢复的 Transcript 使用同一画廊。单张缩略图最多 24×12 个终端 cell，多张使用 10×5 的格子并随宽度换行。支持 Kitty graphics 的终端显示 PNG；tmux、screen、未支持图形协议的终端和其他格式保留可点击的文字及相同格子空间。窗口小于 40×12 时暂停图形显示。

点击缩略图或文字打开消息区域内的图片预览，输入草稿及阅读位置保留，后台 Run 继续。预览显示格式、像素尺寸、原始字节大小和名称，并在打开时快照当前 Transcript 的全部图片；同一图片多次出现仍分别计数，后台新增图片不会改变已打开的画廊。左右键和 ‹/› 切换图片，在边界停止。

支持 PNG 图形且终端提供 cell 像素尺寸时，100%、+/- 可在 1×、2×、4×、8× 间检查原始像素区域；四向按钮、拖动图片和滚轮平移裁剪区域。Fit 恢复等比例全图。缺少图形支持或 cell 像素尺寸时禁用缩放和平移，仍可查看元数据及使用 Fit。终端选择缩放过滤方式。

Esc、Ctrl+C、Enter 或点击消息区域中卡片外的位置关闭预览，关闭按键不会提交草稿或中断 Run。预览期间消息缩略图保留布局并暂停图形显示。审批、提问、计划评审、新 Session 及 conversation Rewind 接管时关闭预览。

只有卡片底部的“打开原图”调用系统查看器。正在打开时再次点击不会重复启动；失败显示原因，可以再点击重试。原始文件通过现有 frontend host 导出到私有临时目录，关闭 TUI 时等待正在进行的打开操作结束后清理；消息点击本身不会启动外部应用。名称是经过控制字符过滤和宽度限制的显示数据。
